ℹ️ About FoodHub

FoodHub is a full-stack food ordering web app built as a Frontend Engineering course project — HTML, CSS and JavaScript on the frontend, Node.js (Express) powering REST APIs, MongoDB storing users, restaurants, menus and orders, all tied together with clean application design.
